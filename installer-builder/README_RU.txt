KODARA Studio Code — сборщик установщика Windows
=================================================

КАК СОБРАТЬ УСТАНОВЩИК
1. Скопируй готовый файл приложения с именем KODARAStudioCode.exe в папку payload.
   Полный путь: payload\KODARAStudioCode.exe
2. Дважды нажми Build-Installer.bat.
3. Если Inno Setup 6 не установлен, скрипт предложит установить его через winget.
   Если winget недоступен, установи Inno Setup 6 с официального сайта:
   https://jrsoftware.org/isdl.php
   После установки снова запусти Build-Installer.bat.
4. Готовый установщик будет здесь:
   dist\KODARAStudioCode_Setup.exe

ЧТО ДЕЛАЕТ УСТАНОВЩИК
- Устанавливает программу для текущего пользователя (обычно без запроса администратора).
- Создаёт ярлык в меню «Пуск».
- Предлагает создать ярлык на рабочем столе (по умолчанию выключено).
- Предлагает запустить приложение в конце установки.
- Добавляет удаление приложения в раздел «Установленные приложения» Windows.

ВАЖНО
- Сборщик не включает файл приложения автоматически: ты сам кладёшь KODARAStudioCode.exe в payload.
- Установщик копирует только EXE. Если приложению нужны отдельные файлы рядом с EXE,
  их надо добавить в секцию [Files] файла KODARAStudioCode.iss.
- Для изменения версии поправь MyAppVersion в начале KODARAStudioCode.iss.
- Inno Setup — сторонний компилятор установщиков; загрузка идёт с его официального сайта/через winget.
